# Student Enrollment System (Java CLI)

Console-based student enrollment system developed as an academic object-oriented programming project.

This application simulates a simplified enrollment workflow including education selection, program/strand selection, schedule preference, payment validation, and automatic student number generation.

--- 

## Features

- Education level selection (College, Senior High School, Junior High School, Kinder & Grade School)
- Program / strand / grade level selection
- Automatic student number generation
- Schedule selection (Blended or Traditional)
- Enrollment fee calculation
- Payment validation
- Overpayment and insufficient payment handling
- Enrollment status summary display

## Built With

- Java
- Java Standard Library (Scanner, DecimalFormat)
- Command-Line Interface (CLI)
